> A curated list of resources for developer education, engineering onboarding, technical writing, interactive coding platforms, and developer relations (DevRel).

Developer education encompasses the methodologies, platforms, and documentation structures designed to help software engineers learn new technologies, onboard into codebases, and master technical skills. This list is intended for developer advocates, technical writers, engineering managers, and developer relations professionals.

## Interactive Learning Platforms

Open-source engines and frameworks for building interactive coding tutorials, sandboxes, and self-paced technical courses.

- [TutorialKit](https://github.com/stackblitz/tutorialkit) — Open-source framework by StackBlitz for building interactive, WebContainers-powered coding tutorials.
- [Katacoda Alternative Tools](https://github.com/killercoda) — Interactive browser-based hands-on environments for Kubernetes, Linux, and DevOps learning.
- [Codecademy Open Curriculum](https://github.com/codecademy) — Open-source course structures, interactive exercises, and lesson schemas for teaching programming languages.
- [Exercism](https://github.com/exercism/exercism) — Open-source code practice platform offering mentored learning paths across dozens of programming languages.

## Technical Writing & Documentation

Tools, style guides, and static site generators for creating clear, developer-focused documentation and technical guides.

- [Docusaurus](https://github.com/facebook/docusaurus) — Open-source static site generator optimized for building developer documentation websites quickly.
- [Google Developer Style Guide](https://github.com/google/styleguide) — Comprehensive guidelines for technical writers creating clear, consistent developer documentation.
- [Vale](https://github.com/errata-ai/vale) — Command-line linter for prose that enforces custom technical style guides and documentation standards.
- [Diátaxis Framework](https://diataxis.fr/) — Systematic framework for structuring technical documentation into tutorials, how-to guides, reference material, and explanations.

## Developer Onboarding & Internal Edu

Frameworks and repositories for structuring engineering onboarding, internal wikis, and technical skill matrices.

- [Developer Onboarding Checklist](https://github.com/sindresorhus/awesome) — Modular templates and workflows for ramping up new software engineers effectively.
- [Engineering Management Institute Resources](https://github.com/eng-management) — Open collection of technical career ladders, skill matrices, and mentorship program templates.

## Developer Relations & Advocacy

Strategies, toolkits, and metrics platforms for managing developer ecosystems and technical advocacy programs.

### Metrics & Community Analytics

- [Orbit Model](https://github.com/orbit-love/orbit-model) — Framework for tracking and measuring developer community engagement and advocacy impact.
- [Common Room Open Integrations](https://github.com/commonroom) — Workflows for aggregating signals across GitHub, Discord, and Discourse for developer program leads.

### Sample Code & Tutorials

- [Awesome README](https://github.com/matiassingers/awesome-readme) — Curated list of exemplary README files that effectively onboard developers to open-source projects.
